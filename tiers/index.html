    How to read this page: the tiers, the filter levels, and the items in no tier

    How to read it

    How the Erazure loot filter shows unique and set items that drop unidentified: the tier each one is in, and when the others are shown quietly or hidden. Everything here is read from the filter's own rules. Once identified, an item shows its own name and the tags of its rolls: open Once identified under an item to see them.

    • Each line is one case: when it applies, the tier, the label as the game draws it, the minimap icon, and the drop sound. A tier named alone notifies as usual (see Tiers); otherwise the difference follows in brackets.
    • Press ▶ beside a sound to hear it. Point at the sound for its number: type .playsound and that number in game to hear it there.
    • Items on the same base share a tier. Unidentified, the filter cannot tell them apart: Lightsabre and Azurewrath are both a Phase Blade.
    • Hidden items still show their name in town. Until you've discovered an item (the Holy Grail Discovery Progress) it is never hidden and always gets a minimap icon and a chat notification when it drops, on every filter level, and a drop sound (its own, or the Grail sound where it has none), and wherever it isn't High or Medium value (set rings and amulets too) it shows the Grail look: an orange star on each side (a Minimal value unique and a Medium value set item have a Grail look of their own). An item on a base with several uniques, like Thunder Maul, counts as discovered once you've found all of them.
    • The game's Force Show Unowned option (in its Loot Filter options, off by default) also shows the ones you have discovered but don't own yet where the filter would hide them, with the game's plain name instead of these looks.
