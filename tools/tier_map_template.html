Erazure Unique & Set Tiers

How to read it

How the Erazure loot filter shows unique and set items that drop unidentified: the tier each one is in, and when the others are shown quietly or hidden. Everything here is read from the filter's own rules. Once identified, an item shows its stats instead.

  • Each line is one case: when it applies, the tier, the label as the game draws it, the minimap icon and the drop sound. A tier named alone notifies as usual (see Tiers); otherwise the difference follows in brackets.
  • Point at a sound for its number: type .playsound and that number in game to hear it.
  • Items on the same base share a tier. Unidentified, the filter cannot tell them apart: Lightsabre and Azurewrath are both a Phase Blade.
  • Hidden items still show their name in town. Until you've discovered an item (the Holy Grail Discovery Progress) it is never hidden, and outside the value tiers (set rings and amulets aside) it shows the Grail look: an orange star on each side. An item on a base with several uniques, like Thunder Maul, counts as discovered once you've found all of them.
