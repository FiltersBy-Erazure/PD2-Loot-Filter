Erazure Filter Levels

Which level for me?

Answer a few questions for a filter level and a version to start from. Pick the level in game (Esc > Options > PD2 Options), the version in the launcher; change either any time.

How to read it

What each filter level of the Erazure loot filter shows, notifies, and hides, for every kind of item that drops, read from the filter's own rules: the table first, then what changes from one level to the next. Pick your level in game (Esc > Options > PD2 Options, or the Increase / Decrease Filter Level hotkeys); the Horadric Cube's description says which level you are on.

  • Shown for Erazure - Main, on the ground outside town in Nightmare and Hell; a cell's details add what Normal difficulty and special areas change.
  • Each column is a group of filter levels that behave the same; levels that differ only in the Rejuvenation Potion (35%) share one (3-4, 5-6).
  • Many items hide only once your character reaches a level: from clvl 80 means from character level 80. The strip under a cell shows character levels 1 to 99, hatched where items hide. Type your character level in the bar to see your own.
  • Click a cell for its details: which items, when, and what changes in Normal difficulty and special areas. The rows link to the pages with every base and item.
  • Hidden items still show in town, and unique and set items still show until you've discovered them (Discovery Progress). Level 0 hides nothing.
  • Unique and set items drop unidentified: one row per value tier. Non-magical items: two rows each, plain (no sockets, not superior, and no skills) and best case (the most a base can show with any sockets, enhanced defense or damage, or skills); the Non-magical Bases page has every base.
