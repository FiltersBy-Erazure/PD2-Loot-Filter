# Unique & Set Tiers

How the filter shows every unique and set item that drops unidentified, read from the filter's own rules. Pick your
version of the filter in the bar above the list. During the Season 14 beta it describes the Season 14 beta filter.

The game's Force Show Undiscovered option (in its Loot Filter options, on by default) shows a unique or set item you
haven't discovered yet with the game's plain name instead of these looks; so does Force Show Unowned for items you
don't own yet, when you turn it on. Turn them off to keep the looks: the filter never hides an item you haven't
discovered either.
