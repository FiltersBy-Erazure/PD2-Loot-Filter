# Unique & Set Tiers

How the filter shows every unique and set item that drops unidentified, read from the filter's own rules. Pick your
version of the filter in the bar above the list.

The filter never hides a unique or set item you haven't discovered yet and always gives it a minimap icon, a chat
line and a drop sound when it drops, on every filter level (its own sound, or the Grail
sound where it has none). Wherever one isn't High or Medium value (set rings and amulets too), it shows the Grail look: an orange star
on each side (a Minimal value unique has a Grail look of its own). The game's Force Show Unowned option (in its
Loot Filter options, off by default) also shows the ones you have discovered but don't own yet where the filter would
hide them, with the game's plain name instead of these looks.
