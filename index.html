    Erazure's PD2 Loot Filter¶

    A highly stylized loot filter for Project Diablo 2, with multiple filter level tiers for customizable strictness and colorful, intuitive symbols for runes, gems, maps, charms, and more.

    Get started¶

    1. In the PD2 launcher, open Item Filter Profiles, pick Erazure - Main, and click Save Filter on the right side. Not sure which version? Main is the one to start with; Versions says what the others change.
    2. In game, pick your filter level: Esc > Options > PD2 Options, or the Increase / Decrease Filter Level hotkeys (set them in Configure Controls). Your Horadric Cube's description shows the version and level you're on.
    3. Start on level 1, Lowest Strictness: it's for the ladder start and characters up to level ~80. Move to a stricter level as your character outgrows its drops; Filter Levels shows what each one hides. Not sure which? Which level for me? asks four questions.

    The launcher keeps the filter up to date: each update reaches you the next time you press Play. The filter is updated for the Season 14 Alliance ladder; last updated November 27th, 2026 (what's new). Something not working? See Troubleshooting.
